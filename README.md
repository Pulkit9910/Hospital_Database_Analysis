# Hospital_Database_Analysis
### Hospital Database Analysis | SQL

* Analyzed a hospital database containing **patient, admission, doctor, diagnosis, and demographic data** using SQL to extract meaningful healthcare insights.
* Developed SQL queries using **filtering, sorting, aggregation, GROUP BY, HAVING, subqueries, joins, conditional logic, string functions, and date functions** to answer complex business questions.
* Performed analysis of **patient demographics, admissions, diagnoses, allergies, doctor performance, provincial trends, and insurance-based admission costs**.
* Applied advanced SQL concepts including **window functions such as LAG(), date-based analysis, conditional calculations, duplicate identification, and year-wise admission analysis**.
* Generated insights such as **admission trends, patient distribution by province/city, doctor-wise admissions, recurring diagnoses, obesity classification, insurance costs, and patient admission history**.
